# Frontend — RepLog

Aplicação Angular da fase 1 do projeto. A descrição completa está no [README principal](../README.md) e o plano em [docs/planeamento.md](../docs/planeamento.md).

## Comandos

```bash
npm install     # instala as dependências (só na primeira vez)
npm start       # servidor de desenvolvimento em http://localhost:4200
npm run build   # versão final em dist/
```
